# نموذج التصميم السريع

## متى تُستخدم
عندما يطلب المستخدم: صفحة هبوط، لوحة تحكم، نموذج، عرض تقديمي، أو "اعمل تصميم".

## القواعد
1. **ملف واحد دائماً**: `prototype-<name>.html` — كل CSS/JS مضمّن (inline)، لا اعتماديات خارجية (يعمل offline).
2. **عربي أولاً**: `dir="rtl"` وخط system-ui، والنصوص بالمصري المختصر.
3. **اقرأ أولاً**: ابحث عن أي DESIGN.md أو هوية موجودة في المشروع والتزم ألوانها.
4. **تدرّج**: هيكل → ألوان → تفاعل بسيط (JS خام فقط). لا أطر عمل ثقيلة.
5. **تحقق**: افتح الملف في `packages/web` مؤقتاً أو اعرضه عبر سيرفر متولي، وراجع المقاسات قبل التسليم.

## المخرج
ملف HTML واحد + سطر في الرد: كيف يفتحه المستخدم (متصفح مباشرة).
