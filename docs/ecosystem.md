# النظام البيئي حول متولي — تقييم صادق (2026-10-07)

## OpenDesign (nexu-io/open-design — Apache-2.0 ✅)
- **ما هو**: طبقة skills (+MCP) تحوّل أي وكيل CLI إلى محرك تصميم (نماذج HTML/PDF/PPTX، ‏277 plugin، ‏151 نظام تصميم).
- **الحقيقة**: مجاني ومفتوح فعلاً، لكنه **ليس بديلاً جاهزاً** — يحتاج وكيلاً + مفتاحك الخاص (BYOK). درسناه shallow+sparse وحذفنا النسخة.
- **الدمج**: نسق skills متوافق معنا أصلاً. أضفنا `skills/design-prototype/SKILL.md` الخاص بنا (عربي RTL أولاً — ما لا يقدمه).
- **الرخصة**: Apache-2.0 مثلنا — آمنة. لم ننسخ كوداً (مهاراتنا مكتوبة أصلاً).

## MonkeyCode (chaitin/MonkeyCode — AGPL-3.0 ⚠️)
- **ما هو**: منصة تطوير سحابية للفرق + نسخة مجانية في المتصفح (بدون رامات محلية ✅).
- **الحصة**: الرسمي **10M توكن/يوم** مجاناً؛ رقم 30M تسويقي (يوتيوب + باقات صينية أعلى) — contemporary caution: الضجة مدفوعة جزئياً بالتسويق.
- **⚠️ تحذير الرخصة**: AGPL-3.0 — **ممنوع نسخ كوده في متولي** (كان سيفرض AGPL علينا). نتعلم الأفكار فقط.
- **لا API رسمي للخارج**: المنصة *تستهلك* مفاتيح OpenAI-compatible ولا *تعرض* موديلاتها — مشاريع "reverse proxy" تخترق الشروط. **لن نبني عليها.**
- **الاتجاه الشرعي العكسي**: سيرفر متولي (`POST /v1/chat`) يمكن ربطه *داخل* MonkeyCode كمزود مخصص لاحقاً.
- **الاستخدام العملي الآن**: نفّذ مهام متولي الثقيلة في سحابتهم من المتصفح (صفر رامات)، وانسخ الناتج لريبو متولي.
